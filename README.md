One image that sums up Tuesday 17 November 2026: a newspaper front page,
"THE WORLD IN ONE DAY", with the date in the masthead so the day cannot be
missed. The Kerch Bridge strike leads, over panels for the tankers mined
near Hormuz, President Trump's arrival in Manila, the Vulcan rocket failure
and Nvidia's first earnings since founder Jensen Huang's exit. A bottom
band carries the Pentagon's ninth failed audit, the JPMorgan software
outage and the five EU states' Rwanda return hub, and a ticker runs the
day's smaller stories underneath. The panels were painted for this entry
and composited with the headlines into a single 1024x1024 page; the shipped
program is a stdlib-only Python copier that writes the finished image to
the output directory as entry.png.

Entered in make.fun's ["Sum up 17 November's world news in one image"](https://make.fun/bounty/news-image-20261117) bounty.

## Run it

mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
